# 몽글 앱 기획서

## 1. 앱 개요
- 앱 이름: 몽글
- 플랫폼: iPhone 전용
- 개발 언어: Swift
- UI 프레임워크: SwiftUI
- 데이터 저장: Core Data
- 영화 데이터 연동: TMDB API
- 디자인 방향: 귀여운 손글씨체, 심플, 부드럽고 아기자기한 감성

## 2. 앱 목표
- 하루를 감정과 기록으로 남길 수 있는 일기 앱
- 감정별 색상과 이모지로 하루를 한눈에 확인 가능
- 달력 형태로 기록을 정리하고, 날짜별로 확인 가능
- 영화 감상 기록을 포스터 기반으로 한눈에 관리 가능
- 간단한 조작으로 누구나 편하게 사용 가능

## 3. 핵심 기능

### 3-1. 일기 기능
- 감정 선택
  - 행복, 평온, 슬픔, 기쁨, 지침, 설렘 등
  - 감정별 이모지와 색상 표시
- 일기 작성 및 저장
  - 오늘의 하루를 문답형식으로 기록
  - 텍스트 입력 후 저장
- 달력에서 기록 확인
  - 월별 달력 표시
  - 감정 이모지가 달력에 표시됨
  - 날짜를 누르면 해당 기록 확인 가능
- 기록 상세보기
  - 날짜별 기록 열람
  - 감정, 내용, 작성 시간 확인
- 앱 데이터 로컬 저장
  - 기기 내 Core Data에 저장
- 모바일 화면 최적화
  - iPhone 화면 비율에 맞게 구성

### 3-2. 영화 기능
- 영화 목록 관리
  - 포스터 형태로 한 번에 보기
  - 12개 정도 크기의 카드형 포스터 배열
- 영화 검색
  - 우측 상단 + 버튼 누르면 검색 화면
  - TMDB API로 영화 검색 가능
- 영화 상세 입력
  - 선택한 영화의 포스터, 제목, 별점 입력
  - 개봉 연도, 감독, 배우 확인
  - 날짜, 위치, 같이 본 사람, 리뷰 기록
- 영화 목록 표시
  - 포스터, 제목, 별점만 한눈에 보이도록 구성

## 4. 디자인 컨셉

### 4-1. 폰트
- 가장 중요하게 반영할 요소
- 작고 귀여운 손글씨체 느낌
- 둥근 형태, 부드러운 라인, 아기자기한 감성
- “몽 베이비글림” 계열의 느낌을 목표로 함
- 글자는 너무 크지 않게 설정
- 화면 정중앙에 자연스럽게 배치

### 4-2. 레이아웃
- 화면 전체를 중간 정렬 중심으로 구성
- 과하게 복잡하지 않게 유지
- 여백을 충분히 두고 보기 편하게 구성
- UI는 단순하면서도 정돈된 느낌
- 가볍고 편안한 색감 사용

### 4-3. 화면 비율
- iPhone 기준 최적화
- 모바일에 적합한 여백 및 버튼 크기
- 터치 편의성을 우선으로 설계

## 5. 화면 구성안

### 5-1. 홈 화면
- 좌측 상단: 홈 아이콘
- 옆 작은 화살표 버튼
- 일기 / 영화 두 개의 목록 선택 탭
- 일기와 영화 탭은 상단 또는 좌측 영역에 표현

### 5-2. 일기 탭 화면
- 달력 형태의 메인 화면
- 월별 위아래 스와이프
- 달력에서 오른쪽으로 슬라이드하면 날짜별 기록 목록 표시
- 중앙 하단 + 버튼 위치
- + 버튼 누르면 감정 선택 화면으로 이동

### 5-3. 감정 선택 화면
- 감정 이모지 및 이름 선택
- 감정별 색상 배경
- 선택 후 오늘의 기록 작성 화면으로 이동

### 5-4. 오늘의 기록 작성 화면
- 상단에 선택한 감정 표시
- 아래에는 문답형 입력 영역
- 질문형 내용 예시
  - 오늘 하루는 어땠어?
  - 가장 기억에 남는 순간은?
  - 오늘 기분은 어땠어?
  - 오늘 느낀 감정은?
  - 오늘 누구와 함께했어?
  - 오늘의 한 줄 요약은?
- 입력 후 저장 버튼으로 일기 등록

### 5-5. 달력 상세보기 화면
- 선택한 날짜의 기록 표시
- 감정, 기록 본문, 사진(선택) 확인

### 5-6. 영화 탭 화면
- 포스터 기반 영화 목록
- 포스터 크기 적당히 큰 카드형 레이아웃
- 포스터 한 화면에 약 12개 정도 보이도록 구성
- 우측 상단 + 버튼

### 5-7. 영화 검색 화면
- 검색 입력창
- 검색 결과 목록 표시
- 포스터, 제목, 개봉연도, 평점 형태로 보이기
- 영화 선택 시 상세 입력 화면으로 이동

### 5-8. 영화 상세 입력 화면
- 영화 포스터
- 제목
- 별점 설정
- 개봉년도
- 감독
- 배우
- 감상 날짜
- 위치
- 같이 본 사람
- 리뷰 작성
- 다음 버튼 또는 등록 버튼으로 저장

## 6. 사용자 흐름

### 일기 흐름
1. 달력 화면 진입
2. 월별 스와이프
3. 날짜 선택
4. + 버튼 누름
5. 감정 선택
6. 오늘의 하루 문답 작성
7. 저장
8. 달력에 감정 이모지 표시

### 영화 흐름
1. 영화 탭 진입
2. 우측 상단 + 누름
3. 영화 검색
4. 영화 선택
5. 별점 입력
6. 세부 정보 입력
7. 리뷰 작성
8. 저장
9. 포스터/제목/별점 목록에 반영

## 7. 기능 상세 요구사항
- 달력은 월별로 위아래 스와이프 가능
- 각 날짜는 감정 이모지 표시 가능
- 오른쪽으로 스와이프하면 날짜별 일기 목록 노출
- 일기 입력은 문답형 구조로 간단하게 작성
- 영화 탭은 카드형 포스터 목록으로 구성
- 영화 포스터는 표준 크기로 출력
- 입력 항목은 최소화하여 간결하게 구성
- 모든 기능은 모바일에 적합한 간단한 조작 방식을 사용

## 8. 기술 구조

### 8-1. 앱 아키텍처
- SwiftUI 기반 화면 구성
- ViewModel로 상태 관리
- Core Data로 일기 및 영화 데이터 저장
- API Client로 TMDB API 연동

## 9. 기대 효과
- 매일 감정을 기록하는 습관 형성
- 일기와 영화를 함께 관리하는 편리한 생활 기록 앱
- 감정과 추억을 한 번에 정리할 수 있음
- 심플하고 귀여운 UX로 접근성 높음

## 10. 구현 우선순위
1. 달력 기반 일기 작성 기능
2. 감정 선택 및 문답형 기록
3. Core Data 저장
4. 영화 검색 및 포스터 목록
5. 별점, 리뷰, 상세 정보 저장
6. 폰트 및 UI 세부 조정

## 11. 최종 방향성
- 몽글은 단순한 일기 앱이 아니라, 감정 기록과 영화 기록을 함께 담는 감성형 기록 앱
- 복잡한 기능보다 쉽게 쓰는 것이 핵심
- 손글씨체와 단순화된 UI가 브랜드 이미지의 핵심
- 기술적으로는 SwiftUI + Core Data 조합이 가장 안정적

## 12. 추가 메모
- 네이버 영화 API는 구현 가능하지만, 실제로는 TMDB가 더 실용적
- 구글 영화 데이터베이스는 운영상 불안정한 경우가 많아 TMDB를 우선 추천
- 최종 디자인은 귀여운 손글씨와 부드러운 컬러를 중심으로 정리

## 13. 간단한 한 줄 소개
- “하루의 감정과 영화의 순간을 몽글하게 기록하는 나만의 감성 일기 앱”
